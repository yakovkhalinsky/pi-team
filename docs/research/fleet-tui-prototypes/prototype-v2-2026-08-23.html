How to read this prototype

  
    
    
  • Both panels render the same widget output at the same selected width. The only difference is where the widget sits in the screen.
    • 
    
  • Use the width picker (#w=80 / #w=100 / #w=120) and the snapshot picker (#s=idle / #s=one-running / #s=busy) — both are reflected in the URL hash so a link is shareable.
    • 
    
  • The widget is produced by buildWidgetLines(snapshot) in packages/pi-agents-team/dist/extensions/pi-agent-team/index.js (line 387). Output is inlined from tools/rendered.json — no synthetic lines, no editing.
    • 
    
  • The scrollback stub is decorative; its length is fixed at 4–6 lines regardless of the selected width.
    •
